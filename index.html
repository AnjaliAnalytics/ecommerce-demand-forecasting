Data & Methodology

Dataset Selection & Data Cleaning Pipeline

Transforming real-world e-commerce transactional data into clean, structured data models.

Dataset Used & Selection Rationale

Dataset Used: E-Commerce Online Retail Transaction Dataset (UCI Machine Learning Repository).

Why Selected: Captures true e-commerce volatility, multi-item customer shopping baskets, international order variations, and real-world supply chain anomalies (such as customer cancellations and unit price fluctuations).

The Business Problem & Resolution

Business Problem: Static reorder thresholds lead to stockouts on fast-moving SKUs (lost revenue and customer churn) while tying up working capital in excess overstock.

How Resolved: Built an automated SQL & Python data cleaning pipeline, aggregated daily sales into weekly time-series, calculated 95% CSL Safety Stock, and grouped SKUs into 4 actionable risk categories (`REORDER NOW`, `MONITOR`, `SUFFICIENT STOCK`, `POTENTIAL OVERSTOCK`).

Data Cleaning SQL Method

Example SQL CTE used during SQLite warehouse ingestion to eliminate returns and bad records:

WITH CleanedTransactions AS (
    SELECT 
        InvoiceNo,
        StockCode,
        Description,
        Quantity,
        InvoiceDate,
        UnitPrice,
        CustomerID,
        (Quantity * UnitPrice) AS TotalLineRevenue
    FROM raw_retail_data
    WHERE InvoiceNo NOT LIKE 'C%' 
      AND Quantity > 0 
      AND UnitPrice > 0
)
SELECT 
    StockCode,
    STRFTTIME('%Y-%W', InvoiceDate) AS SalesWeek,
    SUM(Quantity) AS TotalWeeklyDemand,
    SUM(TotalLineRevenue) AS TotalWeeklyRevenue
FROM CleanedTransactions
GROUP BY StockCode, SalesWeek;
